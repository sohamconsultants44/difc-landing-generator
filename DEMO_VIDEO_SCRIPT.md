# Demo Video Script - 5 Minutes

## 🎥 Recording Guide

**Total Time:** 5 minutes  
**Software:** OBS Studio, Loom, or any screen recorder  
**Format:** 1080p, 30fps minimum

---

## 📋 Script (Timestamps)

### [0:00 - 0:15] Introduction
**Screen:** Homepage (http://localhost:3000)

**Script:**
> "Welcome to the DIFC AI Landing Page Generator. This is an AI-powered tool that creates data-driven, brand-compliant landing pages using historical campaign data and A/B test results. Let me show you how it works."

**Actions:**
- Show homepage
- Point out navigation (Dashboard, Generate)

---

### [0:15 - 0:30] Dashboard Overview
**Screen:** Dashboard page

**Script:**
> "The dashboard gives you quick access to create new landing pages, browse saved templates, and view campaign insights."

**Actions:**
- Show dashboard cards
- Click "Browse Templates" to show template browser

---

### [0:30 - 2:30] Campaign Form - Fill Out
**Screen:** Generate page - Form tabs

**Script:**
> "To generate a landing page, I'll fill out the comprehensive campaign form. Notice it's organized into 7 tabs for easy navigation."

**Actions:**
- Show all 7 tabs: Basic Info, Messaging, Social Proof, Form Builder, Visuals, SEO & Analytics, Compliance
- Fill out key fields:
  - Campaign Objective: Lead Generation
  - Product Name: "AI Landing Page Generator"
  - Target Audience: "B2B SaaS companies"
  - Primary Offer: "Free trial"
  - Add a few benefits and features
  - Add a testimonial
  - Configure form fields
  - Add SEO keywords

**Highlight:**
- "This form captures all 30+ fields required for landing page generation"
- "Notice the real-time validation and array management"

---

### [2:30 - 3:00] Generate Landing Page
**Screen:** Generate page - Click generate button

**Script:**
> "Now I'll generate the landing page. The system uses AI to analyze campaign data and create optimized sections."

**Actions:**
- Click "Generate Landing Page"
- Show loading state
- Wait for generation (may take 10-15 seconds)

---

### [3:00 - 3:30] Preview & Section Editor
**Screen:** Generated page preview

**Script:**
> "Here's the generated landing page. I can see it has multiple sections: Hero, Features, Testimonials, Form, and Footer. Let me edit a section."

**Actions:**
- Show preview with all sections
- Click on a section in the left sidebar
- Show section editor
- Make a small edit (change text)
- Show preview updates in real-time

**Highlight:**
- "The section-by-section editor lets you fine-tune each component"
- "Changes appear instantly in the preview"

---

### [3:30 - 4:00] Save Template & Download PDF
**Screen:** Generate page - Action buttons

**Script:**
> "I can save this as a template for future use, or download an explanation PDF that details how the design decisions were made based on the data."

**Actions:**
- Click "Save as Template"
- Show success message
- Click "Download Explanation PDF"
- Show PDF download

**Highlight:**
- "Templates make it easy to reuse successful campaigns"
- "The explanation PDF shows data-driven rationale for every decision"

---

### [4:00 - 4:30] Sitecore Export
**Screen:** Generate page - Export button

**Script:**
> "For Sitecore integration, I can export components in BYOC format with one click."

**Actions:**
- Click "Export to Sitecore BYOC"
- Show JSON file download

**Highlight:**
- "Components are ready for Sitecore import"

---

### [4:30 - 5:00] Insights Dashboard
**Screen:** Insights page

**Script:**
> "Finally, let me show you the insights dashboard. This displays campaign performance data, device-specific patterns, and A/B test learnings that inform the generation process."

**Actions:**
- Navigate to /insights
- Show top performing layouts
- Show device patterns
- Show conversion benchmarks
- Show A/B test learnings

**Highlight:**
- "All insights are generated from real campaign data"
- "This data drives the AI's design decisions"

---

### [5:00] Closing
**Screen:** Homepage or summary

**Script:**
> "That's the DIFC AI Landing Page Generator. It combines historical data, A/B test results, and AI to create optimized, brand-compliant landing pages with detailed explanations. Thank you for watching!"

**Actions:**
- Show homepage or summary screen
- End recording

## 🎬 Recording Tips

### Before Recording
1. **Close unnecessary apps** - Clean desktop
2. **Set browser zoom to 100%** - Standard view
3. **Use Chrome/Edge** - Best compatibility
4. **Clear browser cache** - Fresh start
5. **Test all features** - Make sure everything works

### During Recording
1. **Speak clearly** - Enunciate
2. **Move mouse smoothly** - Avoid jerky movements
3. **Pause between actions** - Give viewers time to see
4. **Highlight important features** - Use cursor or zoom
5. **Keep it under 5 minutes** - Be concise

### After Recording
1. **Edit if needed** - Trim dead time
2. **Add captions** (optional) - Better accessibility
3. **Export in 1080p** - Good quality
4. **Upload to YouTube/Vimeo** - Public or unlisted
5. **Add to README** - Include link
